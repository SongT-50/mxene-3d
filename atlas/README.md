# MXene Atlas (early stage)

An evidence-linked map of MXene properties from open-access experimental papers (about 2,600 values from about 650 papers). Each value links to the sentence it came from and to any measurement conditions extracted with it.

- Map: https://songt-50.github.io/mxene-3d/atlas/
- Explore mode (3D): https://songt-50.github.io/mxene-3d/atlas/explore.html
- How to use: https://songt-50.github.io/mxene-3d/atlas/guide.html

**Status:** values have been checked against their source sentences by two AI judges only; no human expert check yet, so nothing is labelled "verified". Completeness and accuracy are not yet confirmed.

**Sources and licences:** source sentences are shown only for papers with a confirmed open licence (CC or public domain; OpenAlex / Europe PMC, checked 2026-10-11). For papers without one (31 papers, 204 values), only the value, conditions and DOI are shown. Facts and values are cited from the original papers.
